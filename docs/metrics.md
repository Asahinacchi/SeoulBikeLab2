
# Лабораторная работа № 5
## Расчёт метрик и подготовка данных для анализа

**Проект:** Seoul Bike Sharing Demand
**Группа:** ИВТ-241

## 1. Аналитический вопрос и метрики

### Аналитический вопрос

В какие часы, сезоны и типы дней наблюдается наиболее высокий и низкий спрос на аренду велосипедов?

### Источник данных

Для расчётов использована аналитическая витрина `hourly_demand.parquet`, подготовленная в лабораторной работе № 4.

Путь к источнику:

`s3://mart/seoul_bike/source_ingested_on=2026-10-13/hourly_demand.parquet`

Период наблюдений: с 01.12.2017 по 30.11.2018.

Количество исходных записей: 8760.

Одна строка витрины представляет одно почасовое наблюдение за количеством аренд велосипедов в определённую дату.

### Используемые метрики

**1. Общее количество аренд (`total_rentals`).**

Метрика показывает суммарное количество аренд велосипедов за рассматриваемый период или выбранную группу.

Рассчитывается суммированием `rented_bike_count`.

В расчёт включены все почасовые наблюдения. Часы, в которые система не работала, сохранены с нулевым количеством аренд согласно правилам качества данных предыдущей лабораторной работы.

Общее количество аренд составляет 6 172 314.

**2. Среднее количество аренд за работающий час (`avg_rentals_operating`).**

Метрика показывает среднее количество аренд за один час, когда система проката функционировала.

Рассчитывается как среднее значение `rented_bike_count` при условии `functioning_day = TRUE`.

Неработающие часы не участвуют в расчёте среднего. Для каждой группы дополнительно сохраняется количество подходящих наблюдений, используемых в качестве знаменателя.

Общее среднее количество аренд за работающий час составляет 729,16.

### Оконная функция

В основной группировке используется оконная функция `SUM(total_rentals) OVER ()`.

Она рассчитывает общую сумму аренд по всем часовым группам и позволяет определить долю каждого часа в общем количестве аренд.

Для защиты от деления на ноль используется `NULLIF`.

Сумма долей всех 24 часовых групп составляет 100 %.

### Выводы

Наибольшее среднее количество аренд в основной группировке наблюдается в 18:00 и составляет 1554,02 аренды за работающий час. Наименьшее значение наблюдается в 04:00 и составляет 137,49 аренды.

При дополнительном разделении по сезонам и типам дней максимальное среднее значение обнаружено летом в будний день в 18:00 — 2327,36 аренды.

Результаты показывают различия в спросе между часами суток, сезонами и типами дней. При этом размер групп различается: например, в основной группировке для каждого часа имеется 365 наблюдений, но количество работающих часов составляет 352 или 353.

Необходимо учитывать, что исходные данные представляют агрегированные почасовые наблюдения за один год, а не отдельные события аренды. Полученные различия не позволяют самостоятельно установить причины изменения спроса.
